# NyayaAI-AI-Powered-Legal-Assistant
• Built a legal Q&amp;A application using Spring Boot, Spring AI, RAG, OpenAI, and PGVector for document-grounded responses and tool-calling workflows.
• Integrated Indian Kanoon search with Redis caching and Resilience4j retry and circuit-breaker policies.
• Implemented Server-Sent Events (SSE) response streaming, JWT authentication, request rate limiting, and persistent conversation history using PostgreSQL and Redis.
